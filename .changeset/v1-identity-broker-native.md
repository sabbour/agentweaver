---
"Agentweaver.Identity.Broker": minor
---

Add the .NET 10/OpenIddict Identity broker with owned PostgreSQL stores,
external OIDC federation, authenticated and CSRF-protected consent,
mandatory S256 PKCE, resource audiences, permanent grants, and refresh replay
revocation. Require explicit host credentials and locked service-image builds.
This is an unpublished P0 foundation; run-grant redemption and Azure
publication remain separate dependencies.
