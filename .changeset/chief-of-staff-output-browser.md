Browse saved run outputs and link whole captures to Priorities. Choose a
project, run, session, capture and file without typing IDs. Reuse the 0.x file
tree and Source/Preview viewer with run-bound Gateway capture reads, paginated
lists, manifest size/hash checks, explicit read errors and stale-read removal.
Priority links reopen the run's Changes tab. The capture list and Priority
picker are new Gateway adapters. Issue and pull request pickers remain pending,
so A2 is still partial.
