Add suggested prompt buttons to the Assistant Run page's empty state so a first-time user or someone doing a quick smoke test doesn't have to think of a prompt themselves. Five ready-to-use example requests (list projects and run status, start a smoke-test run, check the latest run's status, list available MCP tools/skills, and create-a-test-project-then-run) are shown as chips before a conversation exists; clicking one populates the composer for review/edit rather than auto-submitting, matching the existing edit-then-send flow.
