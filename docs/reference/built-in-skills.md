# Built-in skills

Agentweaver bundles reusable, role-neutral skill assets in the catalog resources at `packages/Agentweaver.Squad/Catalog/Resources/skills/`. Each directory contains a `SKILL.md` with a short description, practical guidance, and safety boundaries.

## Available assets

- `architecture-decisions`
- `system-design`
- `ui-accessibility`
- `test-strategy-reproduction`
- `api-data-safety`
- `threat-modeling`
- `delivery-operations`
- `docs-release-notes`
- `writing-editing-fact-checking`
- `prd-prioritization`
- `customer-research-evidence`
- `research-source-quality`
- `prototype-ux`
- `positioning`
- `agent-regression`
- `agent-architecture`
- `agent-tools`
- `prompt-engineering`
- `ai-safety`
- `agent-evaluation`

These files are bundled catalog content only. Blueprint bindings and automatic skill assignment are a later phase and are not active yet. Using a blueprint does not currently attach a skill to an agent or inject its instructions into an agent prompt.
