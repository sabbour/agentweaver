# Browser task guides

Use these pages when you need to complete a task in the Agentweaver browser
app. They describe the checked-in web implementation. You need access
to a configured deployment to perform these tasks; this documentation does
not show that the web app or its owner services are available in your
environment.

<a id="journeys"></a>

Start with [What the web app can do](./00-overview.md) to choose a task and
understand its access boundaries.

| Goal | Guide |
| --- | --- |
| Sign in and open a run | [Sign in and access](./onboarding-auth.md) |
| Find or create a project | [Projects](./projects.md) |
| Change project settings or membership | [Project configuration](./configuration.md) |
| Import or assign a Skill | [Skills and marketplace](./skills.md) |
| Connect GitHub or Copilot | [Account connections](./connections.md) |
| Start or inspect a run | [Runs and sessions](./runs-sessions.md) |
| Search or manage Memories | [Knowledge](./knowledge.md) |
