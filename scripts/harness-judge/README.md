# P1 evidence judge brief

Use this brief only with a separately authorized judge.
The candidate helpers do not launch a model, acquire a token, create another actor, or authorize paid execution.
The released 0.x judge conventions are a reference, not inherited P0 acceptance.

Assess each criterion as `PASS`, `PARTIAL`, `FAIL`, or `CANNOT_DETERMINE`.
State the exact evidence reference and the missing boundary.
Do not replace missing observations with plausible narrative.

| Criterion | Required evidence |
| --- | --- |
| Source identity | Independent observed component, image, and source evidence joined to the exact target. A configured expected SHA is not an observation. |
| Surface parity | Actual retained API, UI, and MCP requests for the same bounded journey and owner contract. Separate controlled fixtures do not prove live cross-surface parity. |
| Gate authority | Current owner request ID, actor, tenant, execution fence, decision-state version, allowed answer, and actual response. Browser text and message acceptance cannot approve or complete a gate. |
| Denial | Actual stale, unauthorized, changed-scope, and unavailable outcomes without an inferred success or a fallback route. |
| Journal replay | Actual scoped event IDs, positions, cursor continuity, and UI order after replay. A local echo or opaque object reference is not durable transcript content. |
| Native execution | Actual pinned SDK/runtime observations and owner receipts. Controlled model output does not prove paid execution or entitlement. |
| Cleanup | Exact test-owned resource identities, current authority, owner cleanup receipts, and verified final state. Closing a client is not project, session, or Environment cleanup. |
| Retained evidence | Redacted JSONL, exact run/source/surface correlation, and explicit fixture boundaries. Credential values and transient raw bodies must not be retained. |

Retain the scenario, surface, exact target/source, tenant/project/run identifiers, observation time, and evidence references with each result.
Use the shared JSONL writer.
Keep an aggregate `PARTIAL` or `CANNOT_DETERMINE` while a required criterion lacks actual evidence.
A source test, green CI job, or a health response cannot authorize deployment, publication, merge, or cleanup.
