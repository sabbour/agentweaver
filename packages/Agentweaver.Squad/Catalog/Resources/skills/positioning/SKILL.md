---
name: positioning
description: Define evidence-based product positioning that differentiates without unsupported claims.
---

## Method

1. Identify target segment, job to be done, alternatives, and the value that matters to that segment.
2. Express the differentiated promise in specific, defensible language.
3. Support claims with evidence and state qualifications, exclusions, and proof gaps.
4. Adapt the message by audience while keeping the core promise consistent.

## Output

- Positioning statement
- Audience message map
- Claim-to-evidence table and validation plan
