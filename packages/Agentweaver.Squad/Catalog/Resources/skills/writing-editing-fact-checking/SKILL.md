## Checklist

- Start with audience, purpose, required decision, and supported key message.
- Organize claims so evidence, uncertainty, dates, and scope remain visible.
- Edit for plain language, concrete verbs, consistent terminology, and concise headings.
- Verify names, numbers, quotations, and causal claims against supplied evidence; label unresolved facts.

## Output

Return a polished draft plus a short fact-check ledger of verified, qualified, and unverified claims.
