## Method

1. Define user problem, desired outcome, evidence, target segment, and non-goals.
2. State functional and quality requirements with measurable acceptance criteria.
3. Compare opportunities by impact, confidence, effort, risk, and dependency rather than urgency alone.
4. Record decision rationale, deferred work, and assumptions needing validation.

## Output

- Problem and outcome statement
- Prioritized requirements with rationale
- Acceptance criteria, risks, dependencies, and open questions
