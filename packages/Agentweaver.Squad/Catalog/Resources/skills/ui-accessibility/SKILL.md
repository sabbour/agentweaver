## Checklist

- Use semantic controls, labels, predictable focus order, and keyboard-complete interactions.
- Preserve visible focus, sufficient contrast, readable zoom behavior, and meaningful error messages.
- Provide text alternatives and avoid conveying state through color, motion, or position alone.
- Test narrow and wide layouts, empty/loading/error states, and assistive-technology-friendly names.

## Output

Report blockers first, then affected flows, expected behavior, and a concrete verification step for each fix.
